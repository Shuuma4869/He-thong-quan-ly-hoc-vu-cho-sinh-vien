# Hệ thống quản lý học vụ cho sinh viên

**Academic Management System (AMS)**

Repository nền cho AMS. Mã nguồn ứng dụng và tài liệu triển khai được phát triển trên branch `AMS-Solution`.

## Trạng thái

Dự án đang ở giai đoạn bootstrap. Các tích hợp Phenikaa, Google Calendar và email chưa được triển khai thực tế.
