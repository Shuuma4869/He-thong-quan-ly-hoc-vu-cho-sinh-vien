# AMS Frontend

Frontend của Hệ thống quản lý học vụ cho sinh viên, xây dựng bằng Next.js, React, TypeScript và Tailwind CSS.

## Chạy local

```powershell
pnpm install
pnpm dev
```

Ứng dụng mặc định chạy tại `http://localhost:3000`.

## Kiểm tra

```powershell
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Dashboard ở giai đoạn bootstrap chỉ thể hiện design system và trạng thái chưa kết nối. Không có dữ liệu học vụ giả được xem như dữ liệu production.
